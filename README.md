# VisionForge 🚀

**VisionForge** — это мощный настольный инструмент для разметки изображений, обучения моделей YOLO и детекции объектов в реальном времени.  
Всё в одном: от создания датасета до тренировки и инференса, без необходимости покидать интерфейс или настраивать сервер.

## ✨ Возможности

- **Интуитивная разметка объектов** – рисуйте bounding box’ы, изменяйте классы, перемещайте, удаляйте. Поддержка отмены (undo).
- **Иерархия классов** – создавайте группы (мегаклассы), объединяйте подклассы, назначайте цвета. Вся структура сохраняется в проекте.
- **Автоматическая разметка** – используйте предобученный детектор YOLO для быстрой первичной разметки всего проекта.
- **Пакетная обработка** – запустите детекцию на всех изображениях из проекта или любой папки, результаты сохраняются в отдельный «авто-проект».
- **Подготовка датасета** – гибко разбейте данные на train/val/test, объедините классы, вырежьте объекты для классификации. Готовый датасет совместим с YOLO.
- **Обучение YOLO** – настраивайте гиперпараметры, аугментацию, запускайте обучение прямо из интерфейса, следите за графиками и логами.
- **Детекция в реальном времени** – оверлей поверх экрана с трекингом объектов (горячие клавиши, настройки).
- **Импорт/экспорт** – поддерживаемые форматы: YOLO, COCO, Pascal VOC. Сохраняйте проекты в собственном JSON с полной иерархией и цветами классов.
- **Статистика проекта** – общая информация, распределение классов, рекомендации по балансу датасета, экспорт в CSV.
- **Настраиваемый интерфейс** – тёмная, светлая и высококонтрастная темы, автоскрытие панелей в полноэкранном режиме. (скоро...)

## 📦 Установка

### Вариант 1: Готовый исполняемый файл (Windows)

1. Скачайте последний релиз со страницы .
2. Распакуйте архив и запустите `VisionForge.exe`.  
   *(При первом запуске будут созданы необходимые папки `data`, `annotations`, `models` рядом с exe.)*

### Вариант 2: Установка из исходников (Python)

```bash
git clone https://github.com/fikstt2/visionforge.git
cd visionforge
python -m venv venv
source venv/bin/activate        # Linux / macOS
# или
venv\Scripts\activate           # Windows
pip install -r requirements.txt
python ui/launcher.py
