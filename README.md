# VisionForge 🚀

**VisionForge** — мощный настольный инструмент для разметки изображений, обучения моделей YOLO и детекции объектов в реальном времени.  
Всё в одном: от создания датасета до тренировки и инференса, без необходимости покидать интерфейс.

## ✨ Возможности

- **Разметка прямоугольниками и полигонами** — рисуйте bounding box'ы и полигоны, изменяйте классы, перемещайте вершины, удаляйте. Поддержка отмены (Ctrl+Z).
- **Иерархия классов** — создавайте группы (мегаклассы), объединяйте подклассы, назначайте цвета. Вся структура сохраняется в проекте.
- **Автоматическая разметка** — используйте предобученный детектор YOLO для быстрой первичной разметки всего проекта.
- **Пакетная обработка** — запустите детекцию на всех изображениях, результаты сохраняются в отдельный авто-проект.
- **Подготовка датасета** — гибкое разбиение на train/val/test, объединение классов, вырезка объектов для классификации. Совместимость с YOLO.
- **Обучение YOLO** — настройка гиперпараметров, аугментации, запуск обучения из интерфейса с графиками и логами в реальном времени.
- **Детекция в реальном времени** — оверлей поверх экрана с трекингом объектов.
- **Импорт/экспорт** — форматы YOLO, COCO, Pascal VOC. Собственный JSON с иерархией и цветами классов.
- **Локализация** — полная поддержка русского и английского языков. Переключение в настройках.
- **Статистика проекта** — распределение классов, рекомендации по балансу датасета, экспорт в CSV.
- **Галерея** — поиск по имени файла, фильтр по классу, выбор размера миниатюр.
- **Темы оформления** — Тёмная (Indigo), Светлая, Высокий контраст.

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `N` | Принудительно начать рисование (даже внутри другого объекта) |
| `B` | Переключиться в режим бокса |
| `P` | Переключиться в режим полигона |
| `T` | Следующий класс |
| `D` | Удалить выделенный бокс |
| `E` | Изменить класс выделенного бокса |
| `S` | Сохранить |
| `A` | Авторазметка текущего изображения |
| `F` / `G` | Предыдущее / следующее изображение |
| `Ctrl+Z` | Отмена |
| `Ctrl+D` | Удалить текущее изображение |
| `F11` | Полноэкранный режим |
| `ПКМ` | Управление классами |

## 📦 Установка

### Вариант 1: Готовый исполняемый файл (Windows)

1. Скачайте последний релиз со страницы [Releases](https://github.com/fikstt2/VisionForge/releases).
2. Распакуйте архив и запустите `VisionForge.exe`.

### Вариант 2: Из исходников (Python 3.9+)

```bash
git clone https://github.com/fikstt2/VisionForge.git
cd VisionForge
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
python ui/launcher.py
```

## 📁 Структура проекта

```
VisionForge/
├── core/                    # Ядро: виджет аннотации, галерея, i18n, миниатюры
│   ├── annotation_widget.py # Виджет разметки (боксы + полигоны)
│   ├── gallery_dialog.py    # Галерея изображений
│   ├── i18n.py              # Система локализации
│   └── thumbnail_bar.py     # Карусель миниатюр
├── detection/               # Детекция и оверлей реального времени
├── locales/                 # Файлы переводов (ru.json, en.json)
├── project/                 # Менеджер проектов, подготовка датасета
├── ui/                      # Интерфейс: главное окно, диалоги, настройки
│   ├── main_window.py       # Главное окно приложения
│   ├── settings_dialog.py   # Настройки
│   ├── theme.py             # Темы оформления (QSS)
│   └── training_widget.py   # Виджет обучения YOLO
├── config.py                # Конфигурация приложения
├── requirements.txt         # Зависимости Python
└── run_tests.py             # Тесты
```
